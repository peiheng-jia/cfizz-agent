# Local experiment cases

This directory is intentionally empty in the GitHub release.  Put private
`.cool`/`.mcool`, BigWig, GTF/GFF, BED/BEDPE and derived result files here (or
use any other directory) and authorize it with:

```bash
cfizz-agent --data-root /path/to/your/case
```

Experiment data, generated figures and caches are ignored by Git and are not
included in the package.
